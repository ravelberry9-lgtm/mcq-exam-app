## Patterns the writer kept repeating
1. Stating a cause as a bare assertion (Gravity decides, rotation bulges, altitude+dark+ice) without the one mechanism step.
2. Using a term or acronym before defining it (Ellipsoid in a table cell, NOAA, GNSS, Latitude, Trench, Equator).
3. Translated sentence frames: stacked "-ఆధారిత / -పొడిగించిన" modifiers, double-reason "ఉండటానికీ…కూ కారణంగా", calques ("కూర్చుంది", "కొలతలు వేశారు", "ద్వారా", "దీనికి భిన్నంగా").
Also: analogies that do not map to the point (squeeze vs spin, shortest vs deepest), and exam blocks that list old/new values without saying which to pick when both appear.
