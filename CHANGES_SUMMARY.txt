KEY IMPLEMENTATION DETAILS
═══════════════════════════════════════════════════════════════════════════════

DATABASE CHANGES:
─────────────────

explanation_history table:
  - Tracks all explanation edits with version numbers
  - Stores editor name, timestamp, and full text
  - Marks current version with is_current flag
  - Indexes on mcq_id for fast lookups

flagged_questions table:
  - Stores device_id + mcq_id combinations
  - Unique constraint prevents duplicate flags
  - Linked to questions table with foreign key
  - Index on device_id for fast lookups

API CHANGES:
───────────

/api/start-exam endpoint:
  NEW PARAMETERS:
    - practice_mode: 'fresh' or 'flagged'
    - from_question: Starting question number
    - to_question: Ending question number

  FILTERING LOGIC:
    1. Collects all available questions
    2. If practice_mode='flagged': Filter to only flagged questions
    3. If from_question/to_question set: Filter by question range
    4. Applies difficulty and source filters as usual
    5. Saves all settings in exam_sessions config

FRONTEND CHANGES:
─────────────────

exam.html:
  - Flag button (🚩) on each question
  - Click toggles flag status (off→on→off)
  - Active state: orange button (#ff6f00)
  - Question grid dots show 🚩 when flagged
  - Device ID stored in sessionStorage
  - Persists across page refreshes during exam

setup.html:
  - Practice Mode section added
  - Two mode buttons: "Start Fresh" and "Flagged Only"
  - Question range inputs (from/to)
  - Range validation (from must be ≤ to)
  - Integration with existing exam setup form

HOW TO USE THE FEATURES
═══════════════════════════════════════════════════════════════════════════════

FLAGGING QUESTIONS:
───────────────────
1. Open practice exam
2. Click 🚩 button on any question
3. Button turns orange = flagged
4. Flag persists to database immediately

FLAGGED-ONLY PRACTICE:
─────────────────────
1. Go to exam setup page
2. Click "🚩 Flagged Only" button
3. Select other exam options (time, difficulty, etc.)
4. Click "Start Exam"
5. Only flagged questions appear

CUSTOM QUESTION RANGE:
─────────────────────
1. Go to exam setup page
2. Enter: From Q: 100, To Q: 150
3. Setup exam as usual
4. Click "Start Exam"
5. Only questions 100-150 appear

EDITING EXPLANATIONS:
────────────────────
1. During practice, click "✏️ Edit Explanation"
2. Modal opens with current explanation
3. Copy-paste explanation from Perplexity/ChatGPT
4. Click "Save Changes"
5. Version history displays below
6. All edits are timestamped and saved
